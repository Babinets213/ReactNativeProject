🛒 C-Shopping RN (React Native + Expo)

A complete e-commerce mobile application built with React Native (Expo).
Includes all essential features of an e-commerce platform MVP: authentication, product catalog, cart, checkout, payments, and order management.

🚀 Technologies

React Native (Expo)

Redux Toolkit + RTK Query

Expo Router

NativeWind (Tailwind for React Native)

✨ Features

🔑 User authentication (login & registration)

📦 Product listing with categories & filters

🛍️ Product details with reviews

🛒 Shopping cart (add / remove items)

💳 Checkout & payments

🔔 Push notifications (order updates)

👤 Profile management (addresses, personal info, order history)

🛠️ Installation & Run

Clone the repo:

git clone https://github.com/huanghanzhilian/c-shopping-rn.git
cd c-shopping-rn

Install dependencies:

npm install

Create a .env file from .env.example and set API base URL:

EXPO_PUBLIC_BASE_URL=https://c-shopping-three.vercel.app

Start the app:

npx expo start

Run on device via Expo Go (scan QR code) or in emulator.
